# Следующие этапы

1. Членство и права каналов: `channel_members`, роли owner/member, приватные каналы, проверка доступа на HTTP, WS и поиске.
2. Состояние прочтения: хранить `last_read_message_id` на сервере вместо локальных индикаторов, синхронизировать между устройствами.
3. Нагрузка: фиксированные профили 10/50/100 клиентов, длительный прогон, распределённые лимиты Redis, метрики Prometheus, профилирование PostgreSQL, fanout только подписчикам канала.
4. Семантический поиск: PostgreSQL с pgvector, таблица `message_embeddings(message_id, model, embedding)`, отдельный worker, versioned embedding model, HNSW и фильтрация прав перед выдачей. Сначала измерить качество на наборе русскоязычных запросов; не смешивать в одном индексе векторы разных моделей.
5. Файлы: S3-совместимое хранилище, лимиты размера, проверка MIME, подписанные URL, антивирусная очередь.
6. Production: приглашения/модерация, восстановление пароля, журнал событий, резервное копирование по расписанию, lifecycle сообщений, deployment migrations с rollback-планом, подписанные клиентские сборки.

Профиль пользователя уже входит в текущую версию. Векторный поиск и перечисленные расширения пока не реализованы.
