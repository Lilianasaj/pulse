## Короткий нагрузочный прогон

Команда: `node scripts/load-local.js --users=5 --messages=100 --rps=40`.

| Метрика | Результат |
|---|---:|
| Пользователей | 5 |
| Отправлено | 500 |
| Принято | 500 |
| Ошибок | 0 |
| Доставок WebSocket | 2500 = 500 × 5 |
| Длительность, секунд | 2.80 |
| Сообщений в секунду | 178.40 |
| p50 / p95 / p99, мс | 3 / 9 / 21 |

Сырой отчёт: `docs/load-result.json`. База SQLite в памяти, процесс и клиенты на одной машине. Скорость ограничивалась задаваемым темпом; это проверка корректности короткого прогона, не измерение максимальной пропускной способности или устойчивости длительной нагрузки. Каждый клиент подписан на все публичные сообщения, поэтому доставок больше, чем сохранённых сообщений.
