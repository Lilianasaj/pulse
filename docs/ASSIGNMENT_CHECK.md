## Минимум для завершения демонстрации

1. Показать переписку двух аккаунтов на компьютере и телефоне через один сервер.
2. Запустить Electron отдельным окном с адресом того же сервера.
3. Если требуется мобильная программа: собрать APK и установить на устройство/эмулятор; подтвердить допустимость выбранного стека.
4. Запустить полный Compose-стек на целевой машине; для обязательного Elasticsearch включить профиль search и проверить индексацию.
5. Выполнить нагрузку на сервере демонстрации и сохранить отчёт.
6. Обновить Electron с устранением npm audit high и проверить десктопную совместимость. Устранить ограничение кириллического SQL-поиска.

Покупка VPS не обязательна сама по себе: исходное задание допускает точку доступа по IP, но требуемую доступность должен подтвердить преподаватель. Учебный LAN-адрес недоступен из произвольной внешней сети.
